About This Project

Dataset

This project uses the Telco Customer Churn dataset — 7,043 customer records with 21 attributes, including demographics, subscribed services, contract details, and billing information. The target variable, Churn, indicates whether a customer left the company (26.5% churned, 73.5% stayed).

Preprocessing

TotalCharges was converted from text to numeric, with 11 missing values (all corresponding to new customers with zero tenure) filled with 0. Numerical features were standardized using StandardScaler, and categorical features were one-hot encoded. Preprocessing was fit only on the training data and applied to the test data separately, to avoid data leakage. Data was split 80/20 with stratification to preserve the churn class ratio.

Algorithms Used

  • Logistic Regression — linear baseline classifier, predicts churn probability via the sigmoid function.
  • Decision Tree — rule-based classifier, tuned via cross-validation to control overfitting.
  • Support Vector Machine (SVM) — RBF-kernel classifier that finds an optimal separating boundary.
  • Random Forest — ensemble of decision trees combined via bagging and majority voting.
  • K-Means Clustering — unsupervised algorithm used to segment customers by tenure and spending.
  • Principal Component Analysis (PCA) — used to reduce dimensionality for 2D cluster visualization.

Evaluation Metrics

Models were evaluated using Accuracy, Precision, Recall, F1-score, and ROC-AUC, along with confusion matrices and 5-fold stratified cross-validation. Given the class imbalance in the dataset, accuracy alone was not used to declare any model "best" — recall (catching actual churners) and ROC-AUC (threshold-independent ranking quality) were weighted alongside precision and F1.

Limitations

  • The model is trained on this specific dataset and may not generalize to other companies or customer bases.
  • Churn predictions are statistical estimates, not certainties.
  • This project does not establish causal reasons for churn — only observed correlations.
  • The training data may contain inherent biases from how it was originally collected.
  • Risk category thresholds (LOW/MEDIUM/HIGH) used on the Predict page are defined for this project's demonstration purposes and are not derived from a validated business cost-benefit analysis.
  • This system is intended as an academic demonstration, not a production-ready business decision-making tool.
